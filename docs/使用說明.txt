# 速成輸入法 — 使用說明

一個**免安裝、免管理員權限、單一檔案**的速成（Quick / Cangjie 首尾碼）輸入法。
專為簡化版／網吧 Windows 而做：不需要安裝任何輸入法框架，雙擊即用。

---

## 一、點樣開始用

1. 將 `QuickIME.exe` 放在任何資料夾（例如桌面、USB 手指）。
2. **雙擊執行**。
3. 右下角時鐘旁邊會出現一個藍色「**速**」字圖示 → 即代表已啟動。
4. 去記事本、瀏覽器、遊戲聊天框，直接打字即可。

> 字典已經**內嵌在 exe 裡面**，唔需要額外檔案。

---

## 二、速成規則（同 Windows 速成一樣）

速成 = 倉頡取「**頭碼**」＋「**尾碼**」兩個字根。

| 鍵 | 字根 | 鍵 | 字根 | 鍵 | 字根 |
|----|------|----|------|----|------|
| a | 日 | b | 月 | c | 金 |
| d | 木 | e | 水 | f | 火 |
| g | 土 | h | 竹 | i | 戈 |
| j | 十 | k | 大 | l | 中 |
| m | 一 | n | 弓 | o | 人 |
| p | 心 | q | 手 | r | 口 |
| s | 尸 | t | 廿 | u | 山 |
| v | 女 | w | 田 | x | 難 |
| y | 卜 | | | | |

**例子**

| 打 | 出 | 說明 |
|----|----|------|
| `a` | 日 | 單碼 |
| `ab` | 明 | 日 + 月 |
| `of` | 伙 你 係 … | 「你」係第 2 個 |
| `vd` | 好 | 女 + 木 |
| `ha` | 白 昏 徇 香… | 「香」係第 4 個 |
| `eu` | 氾 汕 沈 沉… | 「港」係第 16 個 |

---

## 三、按鍵

| 按鍵 | 功能 |
|------|------|
| `空白鍵` | **下一頁**（微軟速成慣例）。到最後一頁再按 = 選第 1 個字 |
| `1` ~ `9` | 選第 1～9 個候選字 |
| `PageUp` / `-` | 上一頁 |
| `PageDown` / `+` | 下一頁（同空白鍵一樣） |
| `退格鍵` | 刪一個輸入碼 |
| `Esc` | 取消這次輸入 |
| `Shift`（單按） | 切換 中／英文 |

**連打**：打滿兩碼之後再打字母，會自動送出第一個字，然後繼續打。
所以你可以一路打 `ab of vd` 連續出字。

---

## 四、系統匣圖示

- **左鍵單擊／雙擊** → 中英文切換
- **右鍵** → 選單
  - 切換中／英
  - 輸入法說明／速成碼表
  - 暫停輸入法（暫時還原鍵盤）
  - 結束

---

## 五、字序說明（重要）

候選字次序**完全依照 Windows 內建速成的排位**（原表 `sort: original`），
**冇做過任何字頻重排**。

原因：速成用家靠記憶「第幾個位」打字，一旦改動次序就會打錯字。
所以你可以放心照住以前嘅習慣打。

---

## 六、如果打唔到字

| 情況 | 解決方法 |
|------|----------|
| 圖示唔見 | 睇下系統匣有冇隱藏圖示（按向上箭頭） |
| 遊戲打唔到 | 遊戲若以「管理員身分」執行，本程式都要用管理員身分執行 |
| 全螢幕遊戲打唔到 | DirectX 獨佔全螢幕可能攔唔到，改用「視窗模式／無邊框」 |
| 防毒軟件詢問 | 因為會用鍵盤掛鉤，選「允許」即可 |
| 想暫時關閉 | 右鍵圖示 → 暫停輸入法 |

---

## 七、移除

1. 右鍵系統匣圖示 → **結束**
2. 刪除 `QuickIME.exe` 即可
3. （可選）刪除 `%APPDATA%\QuickIME` 資料夾，清走設定

**唔會寫入註冊表，唔會裝任何驅動，唔會改系統設定。**

---

## 八、技術資料

- 執行環境：.NET Framework 4.x（Windows 10 內建，唔需要另外安裝）
- 字典：21,701 個字，涵蓋香港增補字符集
- 資料來源：`philipposkhos/rime-ms-quick` 的 `ms_quick.dict.yaml`
  （按 Windows 10 傳統速成排位整理）
- 輸入方式：Win32 低階鍵盤掛鉤 + `SendInput` Unicode 送字
- 候選字送出：直接送 Unicode，唔經剪貼簿，唔會污染你的剪貼簿內容
