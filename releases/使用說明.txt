# 速成輸入法 — 使用說明

一個**免安裝、免管理員權限、單一檔案**的速成（Quick / Cangjie 首尾碼）輸入法。
專為簡化版／網吧 Windows 而做：不需要安裝任何輸入法框架，雙擊即用。

---

## 一、點樣開始用

1. 將 `QuickIME.exe` 放在任何資料夾（例如桌面、USB 手指）。
2. **雙擊執行**。
3. 右下角時鐘旁邊會出現一個藍色「**速**」字圖示 → 即代表已啟動。
4. 去記事本、瀏覽器、遊戲聊天框，直接打字即可。

> 字典已經**內嵌在 exe 裡面**，唔需要額外檔案。

---

## 二、速成規則（同 Windows 速成一樣）

速成 = 倉頡取「**頭碼**」＋「**尾碼**」兩個字根。

| 鍵 | 字根 | 鍵 | 字根 | 鍵 | 字根 |
|----|------|----|------|----|------|
| a | 日 | b | 月 | c | 金 |
| d | 木 | e | 水 | f | 火 |
| g | 土 | h | 竹 | i | 戈 |
| j | 十 | k | 大 | l | 中 |
| m | 一 | n | 弓 | o | 人 |
| p | 心 | q | 手 | r | 口 |
| s | 尸 | t | 廿 | u | 山 |
| v | 女 | w | 田 | x | 難 |
| y | 卜 | | | | |

**例子**

| 打 | 出 | 說明 |
|----|----|------|
| `a` | 日 | 單碼 |
| `ab` | 明 | 日 + 月 |
| `of` | 伙 你 係 … | 「你」係第 2 個 |
| `vd` | 好 | 女 + 木 |
| `ha` | 白 昏 徇 香… | 「香」係第 4 個 |
| `eu` | 氾 汕 沈 沉… | 「港」係第 16 個 |

## 三、按鍵

| 按鍵 | 功能 |
|------|------|
| `空白鍵` | **下一頁**（微軟速成慣例）。到最後一頁再按 = 選第 1 個字 |
| `1` ~ `9` | 選第 1～9 個候選字 |
| `PageUp` / `-` | 上一頁 |
| `PageDown` / `+` | 下一頁（同空白鍵一樣） |
| `退格鍵` | 刪一個輸入碼 |
| `Esc` | 取消這次輸入 |
| `右 Shift`（單按） | 切換 中／英文（可在選單改成左 Shift／兩邊／關閉） |
| `Ctrl+空白` | 預設**攔住**，唔會轉全形（可關閉攔截） |

**連打**：打滿兩碼之後再打字母，會自動送出第一個字，然後繼續打。
所以你可以一路打 `ab of vd` 連續出字。

---

## 三之一、打機黨重點：左右 Shift 分開設定

以前「單按 Shift 就切換中英」對打機的人是個陷阱：
長按左 Shift 跑步，一放開就變英文，角色突然唔受控。

現在：

- **預設只有「右 Shift」單按才切換中／英**，左 Shift 完全留給遊戲
- 按住 Shift 期間再按其他鍵（WASD／方向鍵）→ **一律當長按，唔切換**
- 按住超過 **0.7 秒**才放開 → **一律當長按，唔切換**
- 按住 Shift 期間**完全唔組字**，鍵盤原樣傳給遊戲

要改：右鍵系統匣圖示 → **設定** →

- 「左邊 Shift 單按切換中／英」← 勾了就可以用左 Shift
- 「右邊 Shift 單按切換中／英」← 預設勾選
- 兩邊都不勾 = 完全關閉 Shift 切換（只用系統匣圖示切換）

---

## 三之二、符號：永遠半形，Ctrl+空白可以關

本程式**只送 ASCII 半形符號**，符號唔會變成全形（，。！？）。
需要全形符號時，請用微軟速成或其他輸入法。

`Ctrl+空白` 在微軟速成是「全形／半形」切換，打機緊張時好容易誤按。
本程式**預設完全攔住**（按了完全冇反應，連系統都收唔到）。
想恢復原本行為：右鍵圖示 → **設定** → 取消勾選「攔住 Ctrl+空白」。

## 三之三、聯想字：打完一個字，提示下一個字

打完一個中文字，下面會列出一排「最可能接住落去」嘅字：

```
聯想  你
 1   2   3   4   5   6   7   8   9
好  嗎  係  唔  的  有  會  想  了
1-9 選字   空格 = 取消   Esc = 取消
```

按 `1`～`9` 直接選，選完之後又會再提示下一個字。

### 佢會記住你嘅習慣

呢個係同 Windows 內建聯想字最大嘅分別：**佢會學你**。

- 你打「你」之後成日接「係」，打多幾次，「係」就會由第 3 位爬到第 1 位
- 再多打幾次其他組合，佢就跟住你嘅用字習慣調整
- 越用越貼你，好似拼音輸入法咁

排序規則：**你學過嘅排前（次數多嘅更前），未學過嘅保留出廠次序。**

### 聯想窗操作

| 按鍵 | 功能 |
|------|------|
| `1`～`9` | 選聯想字（選完繼續提示下一個字） |
| `空白鍵` | 收起聯想窗（唔會上屏任何東西） |
| `Esc` | 收起聯想窗 |
| 直接打速成碼 | 照常打字（聯想窗自動收起） |

> 聯想窗 **6 秒**冇用會自動收埋，唔會阻住畫面。
> 聯想字只會建議「單一個中文字」；標點、英文、數字都唔會學。

### ★ 清空聯想字記憶

右鍵系統匣圖示 → **聯想字** → **清空聯想字記憶…**

- 會問你確認一次（因為無法復原）
- 清空之後會返去**出廠預設**嘅聯想詞表
- 你之後再打字就會重新學過
- **速成候選字次序完全唔受影響**

### 唔想用聯想字

右鍵圖示 → **聯想字** → 取消勾選「聯想字」。之後就完全唔會出現聯想窗。

### 聯想記憶存在邊

`%APPDATA%\QuickIME\assoc.txt`（純文字，可以自己開嚟睇、甚至人手改）。
刪掉呢個檔同「清空聯想字記憶」係一樣效果。
若 AppData 被鎖，會改放 exe 旁邊嘅 `QuickIME\` 資料夾。

## 四、系統匣圖示

圖示顏色代表目前狀態，打機時用眼角瞄一眼就知：

| 圖示 | 狀態 |
|------|------|
| 藍色「**速**」 | 中文模式（速成） |
| 灰色「**英**」 | 英文模式 |
| 深灰「**速**」 | 已暫停 |

- **左鍵單擊／雙擊** → 中英文切換
- **右鍵** → 選單
  - 切換中／英
  - **聯想字** →（開啟 / 關閉、清空聯想字記憶）
  - **設定** →（左／右 Shift 切換、攔截 Ctrl+空白、聯想字開關）
  - 輸入法說明／速成碼表
  - 暫停輸入法（暫時還原鍵盤）
  - 結束

---

## 五、字序說明（重要）

候選字次序**完全依照 Windows 內建速成的排位**（原表 `sort: original`），
**冇做過任何字頻重排**。

原因：速成用家靠記憶「第幾個位」打字，一旦改動次序就會打錯字。
所以你可以放心照住以前嘅習慣打。

> **聯想字唔會影響呢個次序。** 聯想字係上屏之後另外彈出嘅建議，
> 佢學你嘅習慣只會改變「聯想窗」裡面嘅次序，速成候選字永遠不變。

## 六、如果打唔到字

| 情況 | 解決方法 |
|------|----------|
| 圖示唔見 | 睇下系統匣有冇隱藏圖示（按向上箭頭） |
| 遊戲打唔到 | 遊戲若以「管理員身分」執行，本程式都要用管理員身分執行 |
| 全螢幕遊戲打唔到 | DirectX 獨佔全螢幕可能攔唔到，改用「視窗模式／無邊框」 |
| 防毒軟件詢問 | 因為會用鍵盤掛鉤，選「允許」即可 |
| 想暫時關閉 | 右鍵圖示 → 暫停輸入法 |

---

## 七、移除

1. 右鍵系統匣圖示 → **結束**
2. 刪除 `QuickIME.exe` 即可
3. （可選）刪除 `%APPDATA%\QuickIME` 資料夾，清走設定同聯想字記憶
   （若 AppData 被鎖，會改放在 exe 旁邊的 `QuickIME\` 資料夾）

**唔會寫入註冊表，唔會裝任何驅動，唔會改系統設定。**

---

## 八、技術資料

- 執行環境：.NET Framework 4.x（Windows 10 內建，唔需要另外安裝）
- 字典：21,701 個字，涵蓋香港增補字符集
- 資料來源：`philipposkhos/rime-ms-quick` 的 `ms_quick.dict.yaml`
  （按 Windows 10 傳統速成排位整理）
- 輸入方式：Win32 低階鍵盤掛鉤 + `SendInput` Unicode 送字
- 候選字送出：直接送 Unicode，唔經剪貼簿，唔會污染你的剪貼簿內容
